# Interlaced/Interleaved 3D
Compatible with devices like:
- LG/Sony 4k OLED/LCD 3D TVs
- LG/Acer/Zalman

Can use <a href="https://helixmod.blogspot.com/2015/10/advanced-3d-vision-configuration.html" target="_blank" rel="noopener noreferrer">Advanced 3DVision Configuration</a> (run as admin) to tweak some advanced 3DVision settings. Some get overriden by 3D Fix Manager
