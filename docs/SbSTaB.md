# SbS/TaB
- Compatible with any SbS or TaB device
- TaB will give you the maximum resolution when converting from interlaced if your display supports it

{% include Injector.md %}

## Configuration
- In `3dvision4all.ini`, set `mode = sbs` for Side-by-Side or `mode = tab` for Top-and-Bottom
- If left/right eyes appear reversed, set `swap_eyes = 1`
- Make sure your SbS/TaB display is set as the primary display in Windows so the injector overlay shows on it
