## Additional Notes and Tools
- If a game doesn't have a Nvidia or 3D Fix Manager profile, you can set the `StereoProfile` flag for any 3D settings to save with `Ctrl + F7`. Reference <a href="https://wiki.bo3b.net/index.php%3Ftitle=Driver_Profile_Settings.html" target="_blank" rel="noopener noreferrer">Bo3b's Profile Guide</a> for how to use Nvidia Profile Inspector to set this and tweak 3D Profile settings.
- Some games may lock the convergence, so you can try <a href="https://helixmod.blogspot.com/2012/06/how-to-unlock-convergence-in-locked.html" target="_blank" rel="noopener noreferrer">Chiri's Tool</a> or <a href="https://helixmod.blogspot.com/2012/11/dx9-11-custom-convergencedepth-bindings.html" target="_blank" rel="noopener noreferrer">Chiri's Other Tool</a> to unlock it
- <a href="https://helixmod.blogspot.com/2015/10/advanced-3d-vision-configuration.html" target="_blank" rel="noopener noreferrer">Advanced 3D Vision Config</a> can also be used to modify certain 3DVision settings. Many can also be edited in 3D Fix Manager
- Frame Sequential 3DVision is unstable on latest drivers and requires setting a custom resolution and removing all other resolutions, but the Interlaced EDID overrides are still working well
